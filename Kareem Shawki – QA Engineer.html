How I report a bug

  
A sample of the format I use, so a developer can reproduce the issue in one pass. This is an illustration, not a real defect.

  

    
OTP screen accepts an expired code Severity: High

    

      
Environment
Android 14 and iOS 17, staging build, Wi-Fi

      
Steps
1. Request an OTP. 2. Wait until the timer reaches 0:00. 3. Enter the expired code and tap Verify.

      
Expected
An “Code expired” message and a prompt to resend.

      
Actual
The user is signed in.

      
Evidence
Screen recording, API response with token, device logs

      
Notes
Likely a server-side expiry check. Retested after the fix on both platforms.
